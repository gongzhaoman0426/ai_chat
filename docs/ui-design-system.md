# 句达桌面端视觉规范

界面以冷白、浅蓝和蓝灰文字构成层次。蓝色用于主操作、当前选中项和发出的消息；标题与正文保持中性色，状态继续使用独立的成功、提醒、错误色。

## 基础色

统一使用 `apps/desktop/src/renderer/styles.css` 中的变量：

| 用途 | 变量 | 颜色 |
| --- | --- | --- |
| 主操作 | `--brand` | `#0660ff` |
| 悬停 | `--brand-hover` | `#004fe0` |
| 选中背景 | `--brand-soft` | `#edf4ff` |
| 页面背景 | `--bg` | `#f3f7fd` |
| 面板 | `--surface` | `#ffffff` |
| 次级表面 | `--surface-subtle` | `#f8faff` |
| 正文 | `--text` | `#202c43` |
| 次要文字 | `--text-2` | `#5f6f89` |
| 辅助文字 | `--text-3` | `#62748e` |
| 分隔线 | `--border` | `#e7edf5` |
| 输入边框 | `--border-strong` | `#d6e0ef` |

## 排版与层次

- 正文以 13px 为基准，控件与说明通常为 12px，11px 用于时间、数量等辅助信息。
- 页标题约 22–24px，面板标题 14–16px；通过字号与字重区分层级，避免把标题全部染蓝。
- 控件、面板、弹窗分别使用 6px、10px、14px 圆角。
- 页面背景衬托白色面板，细边框建立分区，阴影只做轻微补充。
- 输入框和搜索框有统一焦点反馈；保留键盘焦点样式，并响应减少动画偏好。

## 页面应用

- 接待中心：导航、会话列表、聊天区、客户与订单分区清晰；发出消息为蓝底白字，收到消息为白底；输入区域用内嵌边框收拢。
- 问答库：主列表与问答助手各自成面板，表头使用浅色底；问题标题保持深色，行操作保持轻量。窄窗口改为上下排列并允许整体滚动，保证列表有足够高度。
- 店铺与设置：白色表单卡片、细线选项卡、蓝色当前状态；账号与模型的名称保持深色。
- 云端账号与上手引导沿用相同色板、控件和卡片规则。

## 验证

构建后运行 `node scripts/ui-design-check.mjs current`，使用临时数据库检查多个窗口尺寸、会话草稿、导航、详情栏与话术面板，并将截图保存在 `.artifacts/ui-design-current/`。该脚本不使用现有用户资料，也不向客户发送消息；订单、商品与客户详情采用进程内的只读测试响应。
