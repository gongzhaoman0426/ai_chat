# 资源可用店铺与通用问答

> Workflow 扩展已移除，本文中与 Workflow 相关的内容仅为历史记录，见[本地扩展开发](extension-development.md#workflow-已移除)。

## 产品规则

Agent、Skill、Toolkit、Workflow 都支持「可用店铺」：

- 全部店铺：包括后续新增店铺，适用于通用资源。
- 指定店铺：多选；没有选中的店铺表示不可用于接待，不解释为全部店铺。
- 在店铺上下文中新建 Agent/Skill、引导创建客服助手或首次安装扩展，默认该店；复制 Agent 继承原可用店铺；内置资源和升级前资源保持原有全部店铺行为。安装已有扩展的新版本保留已有授权。
- 选择器只列出仍有账号的店铺。离线账号保留可选资格；已移除绑定显示失效，不能在保存时悄悄变为全店通用。

资源的店铺范围、Agent 的挂载配置、店铺的工作绑定各自独立。允许某店使用不代表自动挂载或接待；挂载也不会扩大资源授权。一个共享 Agent 可以同时挂载 A 店 Skill 和 B 店 Workflow，每次运行只装配当前店铺允许的部分。

在 Agent 编辑器、Skill 编辑器、Toolkit/Workflow 详情中点击「可用店铺」配置，保存立即生效，不需要重新发布内容版本。Agent 编辑器的「预览店铺的有效挂载」显示当前草稿的授权范围及包级平台适用性；成员还会受实际平台/账号能力裁剪，子 Agent 的内部资源继续分别校验。

全局工作 Agent 必须允许全部店铺使用。店铺工作绑定只接受该店允许的 Agent。已有绑定因撤权失效时显示失败，不绕过店铺限制回退到另一个 Agent。

## 店铺客服工具

继续使用一个 `builtin/commerce` Toolkit。包定义通用业务动作，宿主根据当前会话固定店铺、账号、买家和平台，再裁剪平台/账号支持的工具成员。拼多多、抖店不需要分别挂载同义工具包，也不为每家店复制代码。

Manifest 的 `platforms` / `requiresOperations` 描述代码适用性；本地「可用店铺」描述授权。两者取交集。旧 `builtin/pdd` 历史调用遵守 `builtin/commerce` 的本地授权，不能通过旧版本绕过限制。

## 运行时与数据

`ResourceScope(kind, resourceId)` 保存 mode、storeIds 和 revision。Agent/Skill 按逻辑 ID，Toolkit/Workflow 按不含版本的 assetId 绑定。授权不写入导出的 Agent JSON、Skill ZIP 或扩展 Manifest；内容修订和代码哈希仍不可变。

装配时过滤挂载资源，包括原生 Skill 虚拟文件树和脚本；执行时再次校验。子 Agent 始终继承当前店铺，父子权限不能互相放大。Workflow 经宿主读取知识、查询平台、执行操作或调用子 Agent 时同样检查。范围修改递增受影响店铺的 replyConfigEpoch，使在途回复在下一次守卫处失效；旧发布快照不能恢复已撤销的授权。已提交平台的操作仍按原发送回执处理，不重放。

Memory 的 thread 包含店铺、会话、Agent 修订和配置代次，避免权限变动后继续引入旧工具上下文；实际消息仍由本店会话历史提供。

IPC：

- `resources.scopes`：只读列表，不触发刷新循环。
- `resources.setScope`：资源类型、逻辑 ID、mode、storeIds、expectedRevision；校验活动资源、当前店铺和乐观锁。
- 创建 Agent/Skill、首次安装扩展可传入 storeScope；更改已有资源使用独立授权接口。

这是可信本地扩展的业务授权边界；扩展脚本的执行权限仍遵守现有本地扩展模型。

## 通用问答与图片

`KnowledgeEntry.storeId` 和 `Attachment.storeId` 允许 null：null 表示通用，非 null 表示该店专属。升级保留所有旧条目的 storeId；不把旧问答批量转为通用。

- 新建问答的「所属店铺」选“不绑定店铺 · 通用问答”即为通用；选择店铺即为该店专属。
- 编辑已有问答可以修改所属范围；保存需同时校验原店铺和旧修订，生成新修订并更新索引。切换范围清除所选图片和商品。未明确更改范围时原归属不变。
- 问答库有「本店与通用 / 仅本店 / 仅通用」筛选。没有连接店铺也可维护通用库。
- 工作台话术弹窗只显示通用和当前店铺条目，显示范围标签，支持文字和图片预览。查询在服务端过滤，界面再次校验范围；其他店铺专属条目不会出现在弹窗。
- AI 向量检索一次查询同时包含本店和通用向量；命中再次检查数据库归属、版本、启用状态、有效期。读取降级同样使用该范围，不增加模型请求。
- 通用图片允许发送到当前店铺会话；店铺图片不能发送给其他店铺，也不能用于新建通用问答。切换新问答的范围清除所选图片与商品。
- 通用问答不能直接绑定商品 ID，避免不同平台/店铺同号商品串用；商品规则应存为专属问答。
- 导入写入选定的本店或通用库；导出仅导出该归属范围，不把本店与通用混合后丢失归属。

同意图或明确关联的本店规则优先于通用规则；商品/条件规则需核对，冲突暂停直答。问答编辑器支持 `scope.overridesEntryId`，生效总览按实际发布版本显示权限与平台能力。详见[接待与问答规则](reception-and-knowledge-rules.md)。

## 自动学习

学习候选始终归属实际来源店铺。通用答案可以作为被引用的证据，但标记为 shared_readonly，不允许自动学习修订或停用通用条目。审批默认发布到来源店铺，用户也可明确选择另一店铺或“全部店铺”发布为通用问答；选定范围和内容一同保存在批准记录中，后台按批准范围发布。修订建议改到其他范围时新增问答，来源店铺原条目不动；停用建议只能处理原条目，不能更改店铺。切换店铺需重新选择图片、商品和覆盖规则。旧审批未记录发布范围时仍按来源店铺处理。

“使用这条回答的前提（可选）”对应 `scope.conditions`，表示业务限制，例如“仅限非预售商品”，不是学习或审批理由；无额外限制时留空。有商品或条件限制的问答交给回复 Agent 核对，不直接按相似度原文发送。

## 升级与验证

迁移 `202609090002_resource_store_scope` 新建授权表并允许知识/附件的空店铺归属；不修改既有聊天、问答归属、已发布修订或工作绑定。

回归包括多平台共享 Agent 的有效工具/Skill/Workflow/子 Agent 过滤、在途撤权与脚本阻止、已装配工具撤权、范围乐观锁、真实本地向量检索、通用图片发送、其他店铺图片拒绝、学习审批隔离，以及 Electron 四类配置入口和话术图片预览。所有平台验证使用隔离夹具，没有真实客户发送或订单变更。
