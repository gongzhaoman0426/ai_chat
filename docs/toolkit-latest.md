# Toolkit 自动使用最新版

更新日期：2026-09-10。

Agent 挂载 Toolkit 的逻辑名称，例如 `builtin/commerce`。每轮回复开始时，使用本机已安装、已启用的最高语义版本，升级工具包无需重新挂载或发布 Agent。旧配置里的 `builtin/commerce@1.0.0` 同样按工具包解析；自定义提示词、模型、店铺绑定和历史 AgentRevision 保留。

## 运行规则

- 版本按 major、minor、patch 数值比较，1.10.0 高于 1.9.0。停用版本不参与选择；没有启用版本时明确报错。
- 内置工具随软件更新，本地扩展通过安装 ZIP 更新。不会从网上自动下载或运行工具代码。
- 在模型请求前一次性解析主助手和子助手的 Toolkit，生成本轮 `agentTree`、实际版本与 `assetLock`。同一轮继续使用这些版本，更新后的新版本从下一轮开始使用。
- `RunConfigSnapshot` 和工具执行记录保存当时实际使用的版本，支持排查；Agent 的历史发布记录不原地改写。
- 工具配置按包继承，读取既有版本的设置。每个范围取最近保存的设置，店铺字段覆盖全局字段；新的 Toolkit 设置写入包名。密钥保持引用，配置并发保存继续校验修订。
- 店铺范围、平台操作、账号能力、子助手能力约束和提交前检查继续生效。跟随最新版不赋予跨店铺能力。
- Workflow 仍使用所选产物，Skill 仍使用 Agent 发布时的内容副本。子 Agent 按当前已发布配置执行，详见 [Agent 发布与店铺应用](agent-publication.md)。

## 页面行为

Toolkit 目录按工具包展示一个条目。Agent 编辑器显示「自动跟随最新 · 当前 v…」，旧版本挂载也显示当前包信息。当前生效配置按最新版成员和真实店铺能力计算，不再让用户在多个同名 Toolkit 之间选择版本。

闲鱼「无需物流发货」属于店铺客服工具的 `ship-order` 成员。旧助手无需重新发布即可取得新版成员；是否可调用仍取决于闲鱼账号能力、当前订单可用操作及商家的交付规则。本次验证使用隔离平台夹具，不执行真实发货。

## 验证

`tests/toolkit-latest.test.ts` 覆盖旧定制助手直接获得闲鱼新工具、运行快照、平台与店铺范围、语义版本排序、主/子助手单轮版本一致、停用版本、配置继承与过期保存。已有 Workflow、Agent 模型和 Skill 快照回归继续保留。
